# Booking Cancellation Request Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a customer booking-cancellation request flow inside the AI chat widget, with staff review in Chat Monitor, configurable policy settings, secure evidence uploads, and manual/auto booking cancellation modes.

**Architecture:** Add a focused `BookingCancellationRequest` model plus `BookingCancellationService` for policy, matching, secure upload, approval/rejection, email, and optional booking state changes. Public cancellation submission lives under `/ai/cancellations`; staff operations extend the existing Chat Monitor controller/UI. Settings are added to the existing Admin Settings page, not a new page.

**Tech Stack:** ASP.NET Core MVC, EF Core/Npgsql, PostgreSQL migrations, xUnit with EF InMemory, Bootstrap/Razor, jQuery/vanilla JS, SignalR ChatHub, MailKit-based `IMailService`.

public class BookingCancellationService : IBookingCancellationService
{
    private const long MaxImageBytes = 5 * 1024 * 1024;
    private readonly ApplicationDbContext _db;
    private readonly ISettingService _settings;
    private readonly IMailService _mail;
    private readonly IWebHostEnvironment _env;

    public BookingCancellationService(ApplicationDbContext db, ISettingService settings, IMailService mail, IWebHostEnvironment env)
    {
        _db = db;
        _settings = settings;
        _mail = mail;
        _env = env;
    }

    public async Task<CancellationPolicyDto> GetPolicyAsync(CancellationToken cancellationToken = default)
    {
        return new CancellationPolicyDto(
            await _settings.GetIntAsync("CancellationNoticeHours", 24),
            await _settings.GetIntAsync("CancellationRefundPercentBeforeNotice", 50),
            await _settings.GetIntAsync("CancellationRefundPercentAfterNotice", 0),
            await _settings.GetStringAsync("CancellationPolicyMessage", "Yêu cầu hủy sẽ được nhân viên kiểm tra và phản hồi qua email."),
            await _settings.GetStringAsync("CancellationHandlingMode", "Manual"));
    }

    // Implement CreateAsync, ApproveAsync, RejectAsync, GetProtectedFilePathAsync.
    // Use exact validation rules from the spec: image required for confirmation proof, reason required for approve/reject, refund bill required for approve.
}
```

Implementation details:
- `SaveProtectedImageAsync(IFormFile file, string folder)` stores under `Path.Combine(_env.ContentRootPath, "App_Data", "SecureUploads", "Cancellations", folder)`.
- Accept only `ContentType.StartsWith("image/", StringComparison.OrdinalIgnoreCase)` and `Length <= MaxImageBytes`.
- Suggested bookings: exact id from `SubmittedBookingCode` when parseable, plus email/phone/name matches; serialize distinct ids using `JsonSerializer.Serialize(ids)`.
- Auto-link only when parsed booking id exists and either email or phone matches the booking.
- `ApproveAsync` loads request and booking, validates fields, saves refund bill, sets request `Approved`, `Refunded`, timestamps, and if setting mode is `Auto`, sets booking `Status = "Cancelled"`; if hourly with slot id, set slot `Status = "Available"`.
- `RejectAsync` validates reason, sets request `Rejected`, leaves booking unchanged.
- Send HTML email via `_mail.SendEmailAsync(request.CustomerEmail, subject, body)`.

using Microsoft.AspNetCore.Mvc;
using WebHomestay.Services;

namespace WebHomestay.Controllers;

[Route("ai/cancellations")]
public class AICancellationsController : Controller
{
    private readonly IBookingCancellationService _service;

    public AICancellationsController(IBookingCancellationService service)
    {
        _service = service;
    }

    [HttpGet("policy")]
    public async Task<IActionResult> Policy(CancellationToken cancellationToken)
    {
        return Ok(await _service.GetPolicyAsync(cancellationToken));
    }

    [HttpPost("submit")]
    [RequestSizeLimit(15 * 1024 * 1024)]
    public async Task<IActionResult> Submit(
        [FromForm] string sessionId,
        [FromForm] string? bookingCode,
        [FromForm] string customerName,
        [FromForm] string customerPhone,
        [FromForm] string customerEmail,
        [FromForm] IFormFile confirmationEmailProof,
        [FromForm] IFormFile? refundQrImage,
        [FromForm] string? refundBankName,
        [FromForm] string? refundBankAccountNumber,
        [FromForm] string? refundBankAccountHolder,
        CancellationToken cancellationToken)
    {
        if (string.IsNullOrWhiteSpace(sessionId) || string.IsNullOrWhiteSpace(customerName) || string.IsNullOrWhiteSpace(customerPhone) || string.IsNullOrWhiteSpace(customerEmail))
            return BadRequest(new { message = "Bạn nhập đầy đủ tên, SĐT và email giúp mình nhé." });

        if (confirmationEmailProof == null || confirmationEmailProof.Length == 0)
            return BadRequest(new { message = "Bạn cần upload ảnh email xác nhận đặt phòng." });

        var request = await _service.CreateAsync(new CreateCancellationRequestDto(
            sessionId, bookingCode, customerName, customerPhone, customerEmail,
            confirmationEmailProof, refundQrImage, refundBankName, refundBankAccountNumber, refundBankAccountHolder), cancellationToken);

        return Ok(new { success = true, requestId = request.Id, status = request.Status, message = "Yêu cầu hủy đã được gửi. Nhân viên sẽ kiểm tra và phản hồi qua email." });
    }
}
```
